# 投机解码思路

# eagle

单独一个draft小模型，让小模型decode多猜几个，大模型一次性全verify验证了。eagle-3可能会用到大模型前面某些token的hidden_state来作为输入提升正确率。

eagle有两个结论：

1.decode换成prefill，让访存瓶颈变成部分算力瓶颈

2.Speculative Sampling，让sample先从draft model采样，p/q决定接受概率。

# 美杜莎

普通大模型只有一个lm_head作为最终的输出，美杜莎给大模型改造多出5个lm_head，分别预测t+1,t+2,t+3,t+4,t+5，由于不同头之间信息不透明，
所以前面几个头保留的token多一点，比如t+1保留三个,t+2保留两天，2*3=6的tree attn验证。

# MTP
<img width="1440" height="795" alt="image" src="https://github.com/user-attachments/assets/31d9d558-0bee-4096-b8b6-72fca16d6648" />
MTP推理很简单，前一层的hidden_state + embd(预测token)，先RMS再linear[2*h,h]再过一个block，最后lm_head。

这里的 $embd_{main}$ = $embd_{MTP}$, $lmhead_{main}$ = $lmhead_{MTP}$，是同一个。

重点是训练：
<img width="896" height="100" alt="image" src="https://github.com/user-attachments/assets/a5050d35-e727-4fb9-892f-fa1841ad29ee" />
MTP公式是这样的，总的LOSS是 $L_{MAIN}$ + 0.3 * $L_{MTP}$，在loss对ce+softma+求导的时候，两个loss分别求出p-y，然后再加起来接着正常往下走。
注意，main和MTP的loss对main有梯度，但是main的loss对MTP模块没有梯度。

因为MTP对让第x个位置能够瞻前顾后，所以对训练效果有提升。


# dflash

eagle没有消除串行，只不过把大模型的串行放到了小模型的串行。

<img width="650" height="390" alt="image" src="https://github.com/user-attachments/assets/bd74b9aa-3f71-45a6-b114-ad241b8f801d" />

总之就是想办法降低draft模型时间，或者接受token数量。

dflash从倒数第二层和倒数第三层均匀抽出五层hidden states并乘自己权重，组成新的状态target feature $H_t$

五个创新点：
## KV Injection
<img width="1006" height="610" alt="image" src="https://github.com/user-attachments/assets/18cd7ab7-9adc-4a46-8d54-501f865f93d2" />

把target hidden state变成一段persistent prefix kv，这样让模型更加记得target info。

## Block Diffusion Parallel
采用diffusion的方式，mask的token双向可见，一次forward预测16个token，一次forward全部给出。

training的时候把Target model完全冻结只训练draft layers。

## Random Masked Blocks & Early Token Loss权重大
普通的block diffusion指死活固定切response，但是这和真实的inference肯定不一致。

训练的时候随机mask block来预测。

并且因为投机解码前面的token最重要，所以损失函数CE多了一个权重，前面的权重最大
